Setup Tecnico

Tracciamento automatico — completamente gratuito

  • Crea un foglio Google Sheets

    Vai su sheets.new → crea il foglio. Il sistema scriverà automaticamente i dati lì.

  • Apri Apps Script

    Dal menu del foglio: Estensioni → Apps Script. Cancella tutto il codice esistente.

  • Incolla il codice qui sotto

    Code.gs — Apps Script

  • Pubblica come Web App

    Distribuisci → Nuova distribuzione → Tipo: App web → Accesso: Chiunque → Distribuisci. Copia l'URL.

  • Rendi il foglio pubblico (solo lettura)

    Nel foglio Google: Condividi → Accesso generale → Chiunque abbia il link → Visualizzatore. Serve per la dashboard.
